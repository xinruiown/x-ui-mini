任意门（端口转发）

三种模式底层都是把本机端口的流量转到目标地址，差别在用法：
中转：中转机，监听后转到下一跳 VPS。
入口：对公网开放监听，把进来的流量转到内网或中转。
落地：落地机接收转发，目标一般是本机或内网服务。

SOCKS5 / HTTP 落地

给本机或内网当出口。对公网开放务必设置用户名密码。监听 127.0.0.1 仅本机可用。

Telegram MTProto

使用 mtg 真代理，不是只生成链接。Telegram 设置 → 数据与存储 → 代理 → 添加代理。
